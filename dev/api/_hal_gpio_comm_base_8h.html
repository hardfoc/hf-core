Detailed Description

hf::HalGpioCommBase: the control-pin hooks on BaseGpio pins.

Hooks (standards/driver.md): GpioSet(pin, signal) and GpioRead(pin, signal) -> bool, for a driver's logical pins (<chip>::CtrlPin) and levels (<chip>::GpioSignal::ACTIVE / INACTIVE). The electrical polarity is the BaseGpio's active state, set by the board.

The adapter maps each pin; chain this base under a bus base:

class HalSpiFooComm final
: public hf::HalSpiCommBase<HalSpiFooComm,
hf::HalGpioCommBase<HalSpiFooComm,
foo::SpiInterface<HalSpiFooComm>>> { public: HalSpiFooComm(BaseSpi& spi, BaseGpio& reset)
noexcept : HalSpiCommBase(spi), reset_(reset) {} BaseGpio* GpioFor(foo::CtrlPin pin) noexcept {
return pin == foo::CtrlPin::Reset ? &reset_ : nullptr; // null: not wired on this board
}
private:
BaseGpio& reset_;
};

Each hook initialises its pin on first use. A pin the board did not wire (GpioFor() returns null) fails the hook with GPIO_ERR_PIN_NOT_FOUND: the driver sees the failure and falls back as its documentation says; nothing is skipped silently.
