Detailed Description

What every Hal{Bus}CommBase adapter base shares: the delay hooks and the port chaining.

A driver's port is a CRTP class whose hooks the adapter implements (standards/driver.md). The Hal{Bus}CommBase classes implement the standard hooks on an interface-wrap Base* object, so a handler's adapter only names its driver's port:

class HalSpiFooComm final
: public hf::HalSpiCommBase<HalSpiFooComm, foo::SpiInterface<HalSpiFooComm>> {
public:
using HalSpiCommBase::HalSpiCommBase;
};
hf::HalSpiCommBase
SPI adapter base.
Definition HalSpiCommBase.h:29

The second template argument is the driver's port base, which the adapter base derives from: its hooks then also hide any forwarding stub an older port declares, so the adapter needs no using declarations. Bases chain, HalSpiCommBase<D, HalGpioCommBase<D, foo::SpiInterface<D>>>, to add the control-pin hooks to a bus adapter.

A hook that fails returns false and keeps the interface code (LastBusError()), so the handler can log it; the driver reports the failure as its Error::Bus.
