noexcept

Configure RSTN as an active-low output (idempotent).

Bno08xHandler::Initialize() pulses RSTN (HardwareReset) before Begin() opens the link, so the pin must be usable before Open() runs. Without this the first reset pulse was dropped: the pin was not yet initialized and SetState() returned GPIO_ERR_NOT_INITIALIZED.
