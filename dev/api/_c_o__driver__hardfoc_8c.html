Detailed Description

Generic CANopenNode v4 driver: one CO_CANmodule over N ports.

See hf_co_driver.h for the threading contract. In short:

  • RX: ports push frames into per-port lock-free rings (ISR-safe); CO_CANmodule_process() / hf_co_driver_rx_drain() dispatch them to CANopenNode in thread context, through the RX policy.
  • TX: CO_CANsend() offers the frame to every port without blocking. A port that is full leaves the frame pending in its TX buffer (bufferFull, one pending bit per port); pending frames are re-sent in buffer order from CO_CANmodule_process(), which a port triggers at once with hf_co_driver_tx_done().
  • Error status: port TEC/REC/bus-off and RX overruns map to the CO_CAN_ERR* bits; bus-off ports get a recovery request.
