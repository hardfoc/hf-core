Detailed Description

Transport-neutral CAN frame and the ICanPort interface for port bindings (EspTwaiPort, LinuxSocketCanPort, PipePort, later FDCAN and the wireless tunnels).

Mirrors vortex::contracts::ICanPort (hardfoc-vortex-v1 contracts/can_frame.hpp) so a product can use either: same frame layout, same flag bits, same result and state enums. Two additions:

  • an optional TX-done sink, through which a port tells the CO driver that it has room again (hf_co_driver_tx_done());
  • the RX sink returns whether it took the frame. A hardware port ignores the answer (a frame it cannot hand over is an overrun); a port with RxBackpressure() (the host pipe bus) keeps the frame and offers it again later, so a slow receiver slows the bus down instead of losing frames.

Send never blocks. The RX sink may be called in ISR context: it copies the frame and returns.
