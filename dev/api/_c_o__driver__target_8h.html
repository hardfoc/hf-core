Detailed Description

CANopenNode v4 target definitions for the generic HardFOC driver (CO_driver_hardfoc.c).

This directory is on the include path instead of CANopenNode's example/, so the stack picks this file up. It provides:

  • CO_CAN_MAX_LEN: payload size of the RX/TX buffers, 8 on classic builds and 64 with HF_CO_CAN_FD=1 (nothing above the port binding assumes 8 bytes);
  • the RX/TX buffer and CANmodule types;
  • the CO locks: one recursive mutex per CANmodule (FreeRTOS on target, pthreads on a POSIX host, nothing on a bare build);
  • the application's stack configuration: hf_co_app_config.h is included first when the application puts one on the include path (HF_CORE_CANOPENNODE_CONFIG_DIR), so its CO_CONFIG_* values win over the module defaults.
