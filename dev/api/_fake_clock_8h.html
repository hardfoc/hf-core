Detailed Description

Controllable time source for hf-core host builds.

The host build defines HF_RTOS_NONE_EXTERNAL_CLOCK, so every clock read and delay in hf-utils-rtos-wrap (os_time_get, os_delay_msec, os_get_elapsed_time_msec, RtosTime::GetCurrentTimeUs, ...) lands here.

  • A delay advances the clock by the requested amount and returns at once.
  • Each clock read advances the clock by AutoAdvanceUs() (default 10 µs), so code that polls the clock until a timeout expires terminates even when nothing else moves time forward.

Tests call Reset() at the start of each case if they depend on absolute timestamps, and SetAutoAdvanceUs(0) for exact timing checks.
