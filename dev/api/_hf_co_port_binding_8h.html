Detailed Description

Attaches an hf::can::ICanPort to a CO driver port slot (hf_co_driver_attach_port()).

The binding owns the C trampolines: driver → port (send, status, recover) and port → driver (RX sink → hf_co_driver_rx_push(), TX-done sink → hf_co_driver_tx_done()). Keep it alive while the port is attached.
