Detailed Description

CRTP adapter connecting BaseSpi interface to ADS7952 SpiInterface.

Bridges the HardFOC BaseSpi abstraction to the ADS7952 driver's CRTP SPI interface, enabling the driver to work with any SPI controller that inherits from BaseSpi (EspSpi, StmSpi, etc.).

Thread Safety: Thread-safe when the underlying BaseSpi is thread-safe.
