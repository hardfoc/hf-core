Detailed Description

hf::HandlerBase: the one handler shape of standards/handler.md, written once.

A handler derives from HandlerBase<Self, Driver> (CRTP) and gets the contract every handler shares:

  • EnsureInitialized(): builds the driver in place (std::optional, no heap) and runs the handler's private initializeLocked(); on failure the driver is destroyed, so the next call retries from scratch.
  • Deinitialize(): runs the optional private deinitializeLocked(Driver&), then destroys the driver.
  • IsInitialized(): no lock, no I/O.
  • VisitDriver(fn): under the locks, fn(driver) returns an hf::Status; NotInitialized without calling fn before initialisation. The only way to reach the driver.
  • Header() (protected): a copy of the DiagnosticsHeader. Each handler's GetDiagnostics() returns its own struct whose first member is that header.

Typed methods use CallDriver(fn): locks, initialises on demand, calls fn(driver) (which returns an hf::Result) and counts the outcome.

class FooHandler : public hf::HandlerBase<FooHandler, foo::FOO<HalI2cFooComm>> {
public:
explicit FooHandler(BaseI2c& i2c, hf::HandlerMutex* bus_mutex = nullptr) noexcept
: HandlerBase(bus_mutex), comm_(i2c) {}
~FooHandler() noexcept { DestroyDriver(); } // the driver refers to comm_
hf::Result<float> ReadTemperatureC() noexcept {
return CallDriver([](Driver& d) { return ToResult(d.ReadTemperatureC()); });
}
private:
friend HandlerBase;
hf::Result<void> initializeLocked() noexcept { // locks held, no driver yet
if (!comm_.EnsureInitialized()) return {hf::Status::DependencyNotReady, 0};
return ToResult(EmplaceDriver(comm_).Initialize());
}
HalI2cFooComm comm_;
};

Why CRTP rather than a member object: the public contract is then written once and cannot drift between handlers (today's two families differ exactly there), dispatch stays static, and nothing here names an MCU: only rtos-wrap, hf_time and hf::Status.

Locking: the handler's own recursive HandlerMutex, then the shared bus mutex if one was given, always in that order, for the whole call. Header() takes only the handler mutex.
