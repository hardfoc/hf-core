Detailed Description

ICanPort over the ESP32 TWAI controller (EspCan, BaseCan v2).

  • Send is EspCan::TrySendMessage: the frame takes a free TX slot or the call returns QueueFull at once (no wait, no delay).
  • RX uses EspCan::SetReceiveCallbackEx: the TWAI RX ISR converts the message to a CanFrame and calls the sink (hf_co_driver_rx_push(): a lock-free ring copy). Nothing else may register a receive callback on the same EspCan.
  • Status is EspCan::GetBusStatus (state, TEC/REC, overruns, bus-off count); Recover is EspCan::RequestBusRecovery.
  • EspCan v2 has no TX-done hook for users, so frames left pending are re-sent from CO_CANmodule_process() (the service thread runs at least every millisecond while frames are pending).
