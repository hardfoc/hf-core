Detailed Description

CRTP adapter that turns a BaseUart& into a transport the templated fdo2::Driver<UartT> can drive.

Notes
  • read() returns one complete reply line, CR included, as the driver requires (a line without its CR is a ProtocolError), or 0 when no whole line arrived within the timeout. A partial line is kept for the next call; flush_rx() drops it. BaseUart::Read reports a status, not a count, so bytes are read one at a time while BytesAvailable() is non-zero.
  • All timing (delays, deadline tracking) goes through the hf-utils-rtos-wrap os_* primitives — the handler has zero direct ESP-IDF / FreeRTOS dependencies, so the same code path works against any RTOS the wrapper supports.
