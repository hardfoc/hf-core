Detailed Description

template<typename Derived, typename DriverT>
class hf::HandlerBase< Derived, DriverT >

CRTP base of every handler.

Template Parameters
DerivedThe handler. Privately, with friend HandlerBase;, it defines hf::Result<void> initializeLocked() noexcept (required: build the driver with EmplaceDriver(), probe the chip, apply the configuration) and may define hf::Result<void> deinitializeLocked(Driver&) noexcept (put the chip in a safe state).
DriverTThe driver type, stored in place.
