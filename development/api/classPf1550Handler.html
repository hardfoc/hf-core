Detailed Description

Thread-safe PF1550 PMIC HAL handler.

Owns:

  • a HalPf1550Comm bus adapter,
  • a pf1550::PF1550<HalPf1550Comm> driver instance,
  • the most recently captured pf1550::DiagnosticSnapshot (cached for cross-thread reads).

Lifecycle:

  1. Construct with bound BaseI2c and optional strap BaseGpio* pins.
  2. Call EnsureInitialized (idempotent) before any other method.
  3. (Optional) host calls ApplyProfile with a register-write table. ApplyPortentaH7CarrierProfile is a driver-named eval sequence for ESP examples — not a product board bind.
  4. Periodically call RefreshDiagnosticSnapshot from a monitor thread.
