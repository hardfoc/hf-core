Detailed Description

CRTP register transport bridging bmp581::BusInterface to a BaseI2c device.

Frames writes as [reg, data…] and reads as write-reg / read-len through member scratch buffers (internal SRAM).

Note
Does not own the BaseI2c; it must outlive the adapter.
