Detailed Description

HAL handler for NKK ISF15ACP4 SmartDisplay OLED pushbutton (SSD1331 SPI).

Bridges BaseSpi + BaseGpio to the CRTP isf15acp4::SmartDisplay driver. Software chip select is required — CS is driven via BaseGpio, not SPI hardware CS.
