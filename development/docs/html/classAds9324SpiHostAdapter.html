Detailed Description

CRTP adapter connecting BaseSpi + CONVST/DRDY GPIO to the ADS9324 driver.

Implements both ads9324::SpiInterface and ads9324::HostInterface so a single object can be passed as the driver's SpiType and HostType.

Note
DelayUs is a calibrated busy loop (no RTOS microsecond delay in hf-core). DelayMs uses os_delay_msec.
Warning
SPI Transfer return codes are currently ignored — the driver treats config writes as infallible.
