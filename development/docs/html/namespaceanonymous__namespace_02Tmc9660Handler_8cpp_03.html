Map TMC9660 ACTIVE/INACTIVE onto BaseGpio logical state.

ESP32 bus uses physical levels via CommInterface::signalToGpioLevel (RST/DRV_EN active-HIGH, WAKE/FAULTN active-LOW). On STM32 the PCAL BaseGpio pins already carry that polarity — do not re-apply pinActiveLevels_ here (that double-mapped and inverted nWK/nFLT).
