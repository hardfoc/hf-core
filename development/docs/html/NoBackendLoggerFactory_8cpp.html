Detailed Description

Logger::CreateDefaultBaseLogger() for builds with no MCU (HF_CORE_MCU=NONE).

A host build has no default log transport, so the factory returns nullptr and Logger::Initialize(config) returns false. Host code that wants log output injects a backend with the two-argument overload:

Logger::GetInstance().Initialize(LogConfig{}, std::make_unique<MyHostLogger>());
