Detailed Description

CRTP SPI/GPIO adapter bridging BaseSpi + BaseGpio to isf15acp4::SpiInterface.

Parameters
spiHost SPI (transactions started after CS/DC/reset GPIO).
csSoftware chip-select GPIO (required — not hardware CS).
dcData/command GPIO.
resetPanel reset GPIO.
vcc_enableOptional panel VCC enable; nullptr if hard-wired.
switch_inOptional switch sense GPIO; nullptr if unused.
switch_active_lowTrue when the switch input is active-low.
