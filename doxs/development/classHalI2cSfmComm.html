Detailed Description

CRTP transport bridging sfm::I2cInterface to a BaseI2c device.

SF06 parts use raw command writes and raw multi-byte reads (no register byte). The adapter validates the driver's 7-bit address against the device's configured address, frames through member scratch buffers (internal SRAM, not task stack), and maps a NACKed read to false so the driver can report NoData.

Note
Does not own the BaseI2c; it must outlive the adapter.
