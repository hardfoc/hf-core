Detailed Description

HAL handler wrapping one Dynamixel servo on a BaseUart.

Ownership: the host owns the UART. The handler owns the CRTP adapter, Bus, and Device. Share bus_mutex when another protocol uses the same UART (unusual for Dynamixel half-duplex).
